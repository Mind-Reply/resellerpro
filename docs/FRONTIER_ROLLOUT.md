# Frontier Rollout — Multi-Project Execution

Status: ACTIVE / OWNER-GATED

## Sequence

1. ResellerPro — domain, hosting, deployment and URL control surface.
2. Next confirmed platform/project — only after ownership and repository identity are verified.
3. NovaGaming — only after the exact owned project is identified.
4. Remaining projects — after the first three surfaces have their staff roles, evidence contracts and release gates established.

## Staff pattern

Each project receives bounded roles rather than unrestricted agents:

- Director / orchestrator — coordinates work and dependencies.
- Product engineer — implementation.
- Visual systems lead — abstract identity, interaction and responsive polish.
- Security/proof lead — negative-path and boundary validation.
- Evidence lead — commit, artifact and runtime evidence.
- Integration lead — external services and provider boundaries.
- Research lead — current-state frontier discovery.
- Verification lead — red-team assumptions and unsupported claims.

No role may silently promote another role's work to production.

## Four-hour review target

The review packet should show:
- exact repository and branch
- completed changes
- deterministic validation
- blockers
- provider-side deployment evidence, if any
- canonical URL evidence, if any
- Supabase security findings
- next owner-gated action

No recurring/background execution is implied.
