# ResellerPro — Innovation & Infrastructure Service Catalog

Status: BUILD SPEC / NOT A CLAIM OF LIVE DELIVERY

## Positioning

ResellerPro should present a vertically integrated infrastructure platform: domains and hosting at the foundation, with managed technology services layered above the infrastructure graph.

Primary proof-backed infrastructure surfaces:
- Domains
- Registrar/provider operations
- Hosting
- DNS
- Services
- Executions
- Deployments
- Runtime/evidence

Expansion services should be implemented only when their delivery path, provider integrations, security model, pricing and operational owner are real.

## Service families

### Innovation & Intelligence
- Applied AI and machine learning
- Predictive analytics and decision support
- Intelligent workflow implementation
- Data architecture and analytics

### Core Technology & Development
- IT infrastructure modernization
- Cloud/hybrid architecture
- Application modernization
- Custom application development
- Cloud-native deployment

### Operations, Security & People
- Security engineering and managed protection
- Managed infrastructure/services
- Digital workplace implementation
- Training and technology enablement

## Page contract

Each public service page must contain:
1. Customer problem
2. Outcome and scope
3. What ResellerPro actually operates
4. Architecture / delivery path
5. Integrations and provider dependencies
6. Security and data handling
7. Delivery stages
8. Evidence and verification
9. Commercial entry point
10. Regional availability
11. Clear limitation where a capability is not yet operational

## Regionalization

The page system must support market packs without duplicated application logic:
- BG: Bulgarian + English, BGN/EUR, EU legal/tax context
- UK: British English, GBP, UK domain and commercial context
- Later markets: independent language/currency/tax/provider/policy packs

## Recommended build order

1. Platform / Domains / Hosting
2. Services catalogue and service-detail template
3. Managed Services
4. Security
5. Data & Analytics
6. Application Modernization
7. Infrastructure Modernization
8. Training / Digital Workplace
9. Applied AI/ML

The first services should attach directly to existing ResellerPro infrastructure objects. This creates a credible path from domain/hosting purchase to managed service, execution, deployment and evidence.

## Commercial model

Use three entry types:
- Productized: fixed plans where delivery is standardized
- Assessed: qualification/discovery before a scoped proposal
- Managed: recurring service with measurable operational commitments

Do not publish invented prices or SLA claims. Use request-assessment or verified plan pricing until delivery economics are proven.

## Global readiness

The same service schema should support regional availability flags, localized copy, currency, tax treatment, provider dependencies, data residency requirements and market-specific legal text.
