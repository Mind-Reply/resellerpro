# ResellerPro — reference translation / first platform move

## Source reference

The supplied reference is a Base44 product surface. It was reviewed as a product-architecture reference, not as copy or visual material to reproduce literally.

The useful pattern is the combination of:

- one workspace for apps, websites, agents and tools;
- built-in backend/data/authentication concepts;
- integrations treated as part of the product;
- analytics and growth surfaces after launch;
- strong visual hierarchy with a clear primary action;
- an owner/admin view that exposes the state of the whole portfolio;
- a continuous journey from creation to operation.

## ResellerPro translation

ResellerPro keeps those product principles while preserving its own operating model:

1. Create — apps, websites and bounded agents.
2. Connect — domains, infrastructure, commerce and approved integrations.
3. Release — source, build, preview, approval, execution.
4. Verify — runtime health and independent evidence.
5. Operate — portfolio, workflows, analytics and renewals.
6. Grow — SEO/GEO, social preparation, measurement and optimisation.
7. Govern — permissions, secrets, environment boundaries and audit evidence.

## Public product boundary

The public surface must never invent:

- live provider connectivity;
- customer counts or revenue;
- availability or pricing without a current source;
- completed provisioning;
- payment settlement;
- security certifications not independently verified.

Capability labels therefore distinguish READY, GATED, GOVERNED, TRACEABLE and VERIFY states.

## First implementation move

The canonical `Mind-Reply/resellerpro` repository now carries:

- a complete platform-oriented homepage;
- an interactive workspace surface;
- creation, operation, growth and governance modules;
- the release/evidence rail;
- responsive and reduced-motion behaviour.

Backend/provider execution remains separately gated by verified runtime contracts. The UI is allowed to expose the full operating model without pretending that every adapter is live.
