## 2. VISUAL IDENTITY

### Color Palette

#### Primary Colors
- **Deep Blue** `#0F3A7D` - Trust, stability, professionalism
- **Vibrant Cyan** `#00D9FF` - Innovation, energy, forward-thinking
- **Clean White** `#FFFFFF` - Clarity, space, cleanliness

#### Secondary Colors
- **Slate Gray** `#3D4A5C` - Neutral, sophisticated
- **Success Green** `#10B981` - Positive, confirmation
- **Alert Amber** `#F59E0B` - Attention, caution
- **Error Red** `#EF4444` - Errors, critical

#### Neutral Range
- **Dark Charcoal** `#1F2937` - Text, headings
- **Medium Gray** `#6B7280` - Secondary text
- **Light Gray** `#F3F4F6` - Backgrounds
- **Off-White** `#FAFBFC` - Cards, panels

### Typography

#### Primary Font: Inter
- **Headings (H1-H3)**: 700 Bold
- **Body Text**: 400 Regular
- **UI Labels**: 600 Semibold
- **Code**: Fira Code, 400 Regular

#### Font Sizing
- H1: 48px (desktop), 36px (mobile)
- H2: 36px (desktop), 28px (mobile)
- H3: 24px (desktop), 20px (mobile)
- Body: 16px (desktop), 14px (mobile)
- Caption: 12px

### Logo System

#### Primary Logo
- **Format**: Horizontal lockup (logo + wordmark)
- **Minimum size**: 120px width (desktop), 60px (mobile)
- **Clear space**: 1/2 logo height on all sides
- **Backgrounds**: Deep Blue, White, or Light Gray backgrounds only

#### Logo Variations
1. Full Logo (Horizontal) - Primary use
2. Logo + Wordmark Stack (Vertical) - Navigation, headers
3. Icon Only - Favicon, small spaces (48x48px minimum)

#### File Formats
- SVG (preferred): scalable, web-optimized
- PNG: transparent, 2x/3x resolution
- Never use: JPG (no transparency), scaled versions

### Imagery Guidelines

#### Photography Style
- **Aesthetic**: Modern, clean, professional
- **Palette**: Echoes brand colors (blues, cyans)
- **People**: Diverse, authentic, not staged
- **Focus**: Technology, collaboration, clarity

#### Photography Rules
- Minimum 1200px width
- Use consistent lighting
- Avoid heavy filters
- Show real products/interfaces
- Include people when showing collaboration

#### Illustration Style
- **Approach**: Geometric, minimalist
- **Color**: Use brand palette, 2-3 colors max per illustration
- **Stroke**: 2-3px consistent weight
- **Consistency**: Similar style across all assets

## 3. BRAND VOICE & MESSAGING

### Tone Attributes
- **Professional yet approachable** - Expert without arrogance
- **Clear and direct** - No jargon; explain concepts
- **Confident but honest** - Admit limitations
- **Forward-thinking** - Progressive, not reactionary

### Messaging Hierarchy

#### Primary Message
"The AI operations platform built for enterprises that don't compromise"

#### Supporting Messages
1. "Deploy with confidence—built on military-grade reliability"
2. "Intelligence + transparency + control—the enterprise stack"
3. "From hours of work to minutes of operation—AI that scales"

#### Use Cases
- **Automation**: "Reduce manual work by 80% with zero compromise"
- **Integration**: "Connect everything. Control everything. Automate everything."
- **Intelligence**: "AI that learns your business, not the other way around"
- **Compliance**: "Full audit trails. Complete visibility. Total control."

### Language Guidelines
- ✅ DO: Use "operations," "automate," "deploy," "scale"
- ✅ DO: Active voice ("You deploy" not "it is deployed")
- ✅ DO: Customer-centric ("Your workflow" not "our system")
- ❌ DON'T: Hype words ("revolutionary," "disrupting," "game-changing")
- ❌ DON'T: Vague claims ("best-in-class" without proof)
- ❌ DON'T: Technical jargon without explanation

## 5. WEB PERFORMANCE STANDARDS

### Core Web Vitals Targets
- **LCP** (Largest Contentful Paint): < 2.5s
- **FID** (First Input Delay): < 100ms
- **CLS** (Cumulative Layout Shift): < 0.1

### Performance Budgets
- **Largest Script Bundle**: 250 KB (gzipped)
- **Total CSS**: 50 KB (gzipped)
- **Image Budget**: 500 KB (all combined)
- **Fonts**: 100 KB (2-3 files max)

### Optimization Priorities
1. **Images**: WebP with fallback, lazy-load below fold
2. **JavaScript**: Code-split, defer non-critical
3. **Fonts**: System fonts primary, 1-2 web fonts max
4. **Caching**: 30 days for static, 5 min for dynamic

## 6. SEO STRATEGY

### Target Keywords
- **Primary**: "AI operations platform," "workflow automation"
- **Secondary**: "enterprise automation," "AI deployment"
- **Long-tail**: "automated compliance," "process optimization AI"

### On-Page SEO
- **Title tags**: 50-60 characters, keyword + brand
- **Meta descriptions**: 155-160 characters, CTA
- **Headings**: H1 once, H2 for sections, proper hierarchy
- **Internal links**: 3-5 per page, descriptive anchor text

### Content Strategy
- **Frequency**: 2-3 articles/month
- **Topics**: Use cases, integration guides, industry trends
- **Optimization**: Target 1-2 keywords per article
- **Updates**: Refresh top performers quarterly

## 9. COMPLIANCE & STANDARDS

### Accessibility (WCAG 2.1 AA)
- ✓ Minimum contrast ratio: 4.5:1 (AA)
- ✓ Color not sole means of conveying info
- ✓ All interactive elements keyboard-accessible
- ✓ Alt text for all images

### Brand Protection
- ✓ Trademark all key terms (®, ™)
- ✓ Enforce logo usage guidelines
- ✓ Monitor unauthorized use
- ✓ Maintain consistent messaging

### Data Privacy
- ✓ GDPR compliant
- ✓ Clear privacy policy
- ✓ No unauthorized data collection
